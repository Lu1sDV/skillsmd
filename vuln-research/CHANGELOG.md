# Changelog

Promotion ledger for the `vuln-research` skill. Every entry ties a campaign-learned
invariant (or a feature merge) to the gate / doc it landed in, so "learned N times,
promoted 0 times" is **detectable** instead of invisible.

Promotion-entry format (one line per promoted invariant; see `docs/invariant-promotion.md`):

```
vX.Y.Z — promoted INV-id (learned in <campaign>, finding ids …) → <gate/doc edited>
```

All entries land in the **canonical** repo only (`/home/x/Personal_Projects/vuln-research`,
`Lu1sDV/main`); the vendored copy is regenerated by re-sync (`docs/invariant-promotion.md`).
