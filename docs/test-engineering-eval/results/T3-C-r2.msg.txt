The failure is `test_items_are_unchanged[SqliteOrderStore]` with `assert [] == ['a', 'b', 'c']`. This is the defect below, so that case is marked `xfail(strict=True)` with the reason stated.\n\n3. **Defect in the code under test:** with `SqliteOrderStore`, `update_address` deletes the order's items. `save_order` uses `INSERT OR REPLACE INTO orders`, which deletes the old order row and inserts a new one. The `items` table has `ON DELETE CASCADE` and `PRAGMA foreign_keys = ON`, so the items are deleted too. After an address change the order has `items == []`, which breaks the \"items left unchanged\" requirement. `InMemoryOrderStore` is unaffected. A fix would be an `UPDATE orders SET address=?, status=? WHERE id=?` in `save_order`. The `strict` xfail will then report XPASS, so the marker can be removed."
