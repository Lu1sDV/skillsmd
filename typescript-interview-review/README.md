# typescript-interview-review

Explain TypeScript interview questions and small diagnostic examples through their static contract, emitted representation, and JavaScript behavior. The [skill workflow](SKILL.md) uses minimal counterexamples and verifies compiler-sensitive claims in the stated environment.

## Use

`Use $typescript-interview-review to explain this callback-variance question with a compiler-checked counterexample.`

Copy this complete folder, including references and `LICENSE.upstream`, into the skill location supported by your agent.

## References

- [Diagnostic and interview cases](references/diagnostic-cases.md): observable distinctions, focused examples, and assessment criteria.
- [Verified corrections](references/verified-corrections.md): variance, narrowing, satisfies, enums, immutability, keys, and augmentation.
