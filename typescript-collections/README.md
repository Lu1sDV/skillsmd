# typescript-collections

Choose TypeScript collections and runtime APIs with explicit equality, ordering, mutation, memory, and input-size contracts. The [skill workflow](SKILL.md) covers data structures plus text, binary data, iteration, serialization, and cloning.

## Use

`Use $typescript-collections to choose a queue for this workload and check its ordering, retained memory, and complexity.`

Copy this complete folder, including references and `LICENSE.upstream`, into the skill location supported by your agent.

## References

- [Collection invariants](references/collection-invariants.md): arrays, maps, sets, queues, heaps, linked structures, and operation costs.
- [Runtime API checks](references/runtime-api-checks.md): iterators, Unicode, numbers, binary data, dates, JSON, cloning, and lifetime.
