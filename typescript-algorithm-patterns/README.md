# typescript-algorithm-patterns

Choose and verify TypeScript algorithms from explicit preconditions, invariants, mutation rules, and complexity bounds. The [skill workflow](SKILL.md) covers the source's 17 algorithm families and uses bounded independent oracles where they expose meaningful correctness risks.

## Use

`Use $typescript-algorithm-patterns to solve this interval problem, justify the invariant, and check boundary cases.`

Copy this complete folder, including references and `LICENSE.upstream`, into the skill location supported by your agent.

## References

- [Sequence and search](references/sequence-search.md): pointers, windows, search, prefix sums, stacks, maps, heaps, intervals, and cyclic sort.
- [Traversal and connectivity](references/traversal-connectivity.md): BFS/DFS, topological sorting, union-find, and tries.
- [Optimization and enumeration](references/optimization-enumeration.md): backtracking, dynamic programming, greedy choices, and bit operations.
