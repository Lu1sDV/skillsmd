# Universal Research Orchestrator

Organize substantial research, audits, and investigations into scoped research
lanes, synthesis, production, validation, and source preservation. Use it for
codebase audits, framework investigations, security research, or comparisons
that need several sources and explicit confidence judgments.

## Use

```text
Use $universal-research-orchestrator to investigate this framework, cross-check the findings, and produce a cited report with examples and unresolved questions.
```

The [skill workflow](SKILL.md) defines lane prompts, source navigation, synthesis,
output formats, validation gates, and an archive index. Its emphasis is on
distinct research surfaces, concrete examples, contradiction handling, and
traceable evidence. Establish the intended scope and deliverable before
distributing the research work.

## Contents

This bundle keeps its procedures in one entry point:

- [Scope calibration](SKILL.md#phase-0-scope-calibration): define domain, depth, and output.
- [Synthesis](SKILL.md#phase-2-synthesize): reconcile results, confidence, contradictions, and gaps.
- [Validation](SKILL.md#phase-4-validate--quality-gates): inspect citations, examples, and coverage.
- [Source preservation](SKILL.md#phase-5-archive--source-preservation): retain source locations and archival metadata.

## Install

Copy the complete `universal-research-orchestrator/` folder into the skill
directory recognized by your agent, retaining `SKILL.md` as the workflow entry point.
